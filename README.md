# Website Data UMKM

## Deskripsi

Website sederhana untuk menampilkan data UMKM dan produk secara dinamis menggunakan PHP dan MySQL.

Website ini dibuat sebagai proyek pembelajaran basis data, PHP dinamis, dan version control menggunakan GitHub.

## Teknologi yang Digunakan

- PHP
- MySQL
- HTML
- CSS
- Laragon
- DBeaver
- Visual Studio Code
- Git & GitHub

## Cara Menjalankan Project

1. Pastikan Laragon sudah terinstall.
2. Jalankan Apache dan MySQL melalui Laragon.
3. Pastikan database `db_umkm` sudah tersedia.
4. Simpan folder project di:

   `C:\laragon\www\umkm-website`

5. Buka browser.
6. Akses:

   `http://localhost/umkm-website/`
